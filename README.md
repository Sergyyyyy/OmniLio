# OmniLio

A modern personal social-media landing page built with React and Vite. It brings multiple social-media profiles into one clean, responsive page instead of relying on a traditional list of links.

The design uses a dark glassmorphism interface with subtle green accents, inspired by modern Apple interfaces and the concept of Linktree.

## Overview

This project serves as a personal hub for my social-media profiles.

Instead of sharing multiple individual links, users can visit one page and access all of my important social platforms from a single location.

The interface was designed to feel more like a modern mobile application than a traditional website. Social platforms are presented as interactive cards rather than a standard vertical list of buttons.

### Supported Platforms
- Facebook
- Instagram
- TikTok
- LinkedIn
- GitHub
